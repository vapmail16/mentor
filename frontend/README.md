# Mentor Platform Frontend

React + TypeScript + Vite frontend for the Mentor Learning Platform.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Build

```bash
npm run build
```

## Environment Variables

Create a `.env` file:

```env
VITE_API_URL=http://localhost:3001
VITE_FRONTEND_URL=http://localhost:5173
VITE_CASHFREE_APP_ID=your_app_id
VITE_CASHFREE_MODE=SANDBOX
```

## Features

- ✅ Authentication (Login, Register)
- ✅ Protected routes
- ✅ Landing page
- ✅ Dashboard
- ⏳ Payment integration (Cashfree)
- ⏳ Session/video management
- ⏳ Learning paths
- ⏳ Community features
