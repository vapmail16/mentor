## 📝 Next Steps

1. **Clone Repository:**
   ```bash
   git clone https://github.com/vapmail16/mentor.git
   cd mentor
   ```

2. **Setup Environment:**
   ```bash
   # Backend
   cd backend
   cp .env.example .env
   # Edit .env with your actual credentials
   
   # Frontend
   cd ../frontend
   cp .env.example .env
   # Edit .env with your configuration
   ```

3. **Install Dependencies:**
   ```bash
   # Backend
   cd backend
   npm install
   
   # Frontend
   cd ../frontend
   npm install
   ```

4. **Run Application:**
   ```bash
   # Backend (from backend/)
   npm run dev
   
   # Frontend (from frontend/)
   npm run dev
   ```
